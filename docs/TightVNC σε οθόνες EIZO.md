# TightVNC σε σταθμούς με οθόνη EIZO RadiForce MX217

## Το πρόβλημα

Οι γιατροί έχουν γυρίσει τις EIZO από κατακόρυφες σε οριζόντιες. Όταν συνδέεσαι
με TightVNC σε τέτοιο σταθμό, η εικόνα έρχεται **πλάγια**.

**Αιτία:** η ρύθμιση «Use D3D driver if available» του TightVNC Server παίρνει την
εικόνα απευθείας από την κάρτα γραφικών, αφού αυτή την έχει ήδη στρίψει για την
οθόνη. Χωρίς αυτήν, το TightVNC παίρνει την εικόνα από τα Windows, όπου είναι όρθια.

**Λύση:** απενεργοποίηση της ρύθμισης σε κάθε τέτοιο σταθμό. Επιβεβαιώθηκε στο
Popinio στις 16/10/2026 (TightVNC Server 2.8.88).

**Παρενέργεια:** η εικόνα ανανεώνεται λίγο πιο αργά. Αν ενοχλεί, μείωσε το
«Screen polling cycle» από 1000 σε π.χ. 300 ms.

---

## Τρόπος Α — Χειροκίνητα (στον σταθμό ή μέσα από VNC)

1. Δεξί κλικ στο εικονίδιο του TightVNC δίπλα στο ρολόι → **Configuration…**
   (θα ζητήσει τον κωδικό διαχειριστή του TightVNC).
2. Καρτέλα **Server**, πλαίσιο **Update Handling** (κάτω δεξιά).
3. Βγάλε το τικ από το **«Use D3D driver if available»**.
4. **Apply** → **OK**.
5. Αποσυνδέσου από το VNC και ξανασυνδέσου. Η εικόνα πρέπει να έρθει όρθια.

---

## Τρόπος Β — Με εντολή, από τον δικό σου υπολογιστή

Το αρχείο **`tightvnc_eizo_fix.cmd`** (στον ίδιο φάκελο `docs`) κάνει όλη τη
δουλειά για έναν σταθμό. Ο κωδικός του TightVNC **δεν χρειάζεται**: η αλλαγή γίνεται
στο Μητρώο των Windows, που το προστατεύουν τα δικαιώματα διαχειριστή των Windows.

### Προϋπόθεση

Πρέπει να τρέξει με λογαριασμό που είναι **διαχειριστής στον σταθμό-στόχο**
(π.χ. ο λογαριασμός διαχειριστή του δικτύου του νοσοκομείου).

### Πώς το τρέχεις

1. Δεξί κλικ στο `tightvnc_eizo_fix.cmd` → **Εκτέλεση ως διαχειριστής**.
2. Γράψε το όνομα ή την IP του σταθμού και πάτα Enter.
3. Διάβασε τα πέντε βήματα που τυπώνει. Στο τέλος πρέπει να γράφει **ΕΠΙΤΥΧΙΑ**.
4. Ξανασυνδέσου με VNC.

Εναλλακτικά, από γραμμή εντολών: `tightvnc_eizo_fix.cmd PC5068`

### Τι κάνει, βήμα-βήμα

1. Ελέγχει ότι ο σταθμός απαντά στο δίκτυο.
2. Ανοίγει την υπηρεσία «Απομακρυσμένο Μητρώο» (Remote Registry) του σταθμού,
   γιατί στα Windows 10/11 είναι συνήθως σταματημένη. Αν ήταν απενεργοποιημένη,
   την αφήνει ρυθμισμένη σε «χειροκίνητη εκκίνηση».
3. Γράφει `UseD3D = 0` στο `HKLM\SOFTWARE\TightVNC\Server`.
4. Κάνει επανεκκίνηση της υπηρεσίας TightVNC (`tvnserver`) για να διαβάσει τη
   ρύθμιση. **Όποιος είναι συνδεδεμένος με VNC εκείνη τη στιγμή αποσυνδέεται.**
5. Ξαναδιαβάζει τη ρύθμιση για να επιβεβαιώσει ότι πέρασε.

### Αν αποτύχει

| Μήνυμα | Τι σημαίνει |
|---|---|
| «Ο σταθμός δεν απαντά» | Κλειστός, λάθος όνομα, ή το τείχος προστασίας κόβει το ping. |
| Αποτυχία στο βήμα 2 ή 3 με «Access is denied» | Ο λογαριασμός σου δεν είναι διαχειριστής σε εκείνον τον σταθμό. |
| Αποτυχία στο βήμα 3 με «network path was not found» | Το Απομακρυσμένο Μητρώο δεν άνοιξε ή το κόβει το τείχος προστασίας. Κάνε τον Τρόπο Α. |
| Αποτυχία στο βήμα 4 | Η υπηρεσία TightVNC έχει άλλο όνομα ή δεν είναι εγκατεστημένη ως υπηρεσία. |

### Για χειροκίνητη επαλήθευση στον ίδιο τον σταθμό

Σε Command Prompt ως διαχειριστής: `reg query HKLM\SOFTWARE\TightVNC\Server /v UseD3D`
— πρέπει να δείχνει `0x0`.

## Κατάσταση

- Τρόπος Α: **δοκιμασμένος** στο Popinio.
- Τρόπος Β: η εντολή **δεν έχει δοκιμαστεί ακόμη ως το τέλος** σε πραγματικό σταθμό
  (στο σπίτι ο λογαριασμός δεν είχε δικαιώματα διαχειριστή στο Popinio). Πρώτη
  δοκιμή: στο νοσοκομείο.
